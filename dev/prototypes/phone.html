Phone lite: the aggregate Loss Lab at 390 px

dev/prototypes/phone.html · standalone, nothing wired · 2026-09-28

The full app assumes a widescreen and a keyboard. This is the other entry: what a phone in the audience gets when it opens the same URL. The design bet is that a phone user never types DecL, so the editor gives way to a picker of curated examples, and the six tabs give way to the four things that survive 390 px: the facts line, one chart, one small table, and the program itself, read-only. Everything else lives behind the full-site link.

Tokens, type scale, and the selection red are copied from web/src/styles/site.css; the chart line is aggregate.style's first cycle color via the theme.js fallback; the programs are library.agg's Capstone family as written. The density really is a lognormal at mean 18,950 and CV 0.184, computed in this file, so the curve and its quantile marks agree.

Callouts

What is deliberately absent

  • The editor. CodeMirror stays in the bundle for the full app only. On glass, autocorrect fights the grammar and completion popups land under the thumb. The program card is read-only; expansion shows all of it, still read-only.
  • Five of the six tabs. Re, Pricing, PnL, Bounds, More are widescreen work. The lite page is the Overview's soul: facts, one chart, one table.
  • Interactive grids. csv-grid at 390 px is horizontal scrolling misery. Tables arrive static, four rows, formatted short.
  • The 3-D surface. Touch rotation works but the GPU cost is real and the payoff on a 6-inch screen is not. If wanted later, it goes behind an explicit tap that says it is heavy.
  • Hover anything. Title attributes never fire on touch. Every explanation is either visible text (the recipe notes, the chart caption) or gone.

Routing

One URL, no user-agent sniffing, no m-dot redirect. A boot-time branch before anything mounts, with the query param as master override so a desktop window can test the lite shell:

const q = new URLSearchParams(location.search);
const lite = q.has('lite') ? true
           : q.has('full') ? false
           : matchMedia('(max-width: 640px) and (pointer: coarse)').matches;
if (lite) { mountLite(); } else { mountFull(); }

Vite makes the two-entry variant (lite.html + lite.js) equally cheap if keeping the full bundle off the phone matters; the shared modules (api.js, examples.js, charts/theme.js) are the point either way. Note the lite page still needs the api reachable from cell networks, which is the same deployment the widescreen demo needs.
