Quick help

The aggregate Loss Lab. Build and explore compound (aggregate) loss distributions from simple DecL programs.

Try it
agg Demo 100 claims 1000 xs 0 sev lognorm 90 cv 1.5 poisson
then press Ctrl+Enter
Keys
Ctrl+Enterbuild Ctrl+Spaceautocomplete; Tab takes the suggestion Ctrl+Ksearch the example library Ctrl+↑ ↓step through history (or the two arrows in the editor's right margin) Ctrl+Shift+↑ ↓step through the example library (loads, does not build); the counter beside the editor says where you are, and walks whatever the Examples menu is filtered and searched down to Ctrl+Shift+Uflip every table between static and interactive Ctrl+Shift+Vflip every exhibit between the raw frame and the insurer reading; the pair beside the versions says which one you are on Alt+1…6jump to an output group, numbered in the order they are listed below ← → Home Endwalk a group or leaf row once it has focus, skipping whatever is dark ✕clear the editor; press it again on an empty box to clear your history

Ctrl+Shift+V stands aside inside the program box and the entry forms, where the browser claims it for paste, and works everywhere else. Menu ▸ Editor ▸ Emacs keys adds Ctrl+A/E/K/Y, N/P and F/B/D in the program box.

Controls
  • Build: run the program (same as Ctrl+Enter)
  • Examples: load a ready-made program. Type to search it, or click the tag pills to narrow it; the arrow walk follows what is left on screen
  • Reformat: rewrite the program in canonical form, keeping its note{}, hints{} and tags{}
  • Sharpen: audit the grid and move to a better one, writing the hints{} clause that pins it
  • Hints: keep the grid you have and write it into hints{}, so agg.Name elsewhere means one fixed thing
  • PnL: wrap what you built in a profit and loss account. Once a P&L is what you are reading the button becomes Explode, which opens it back into its parts
  • GCN: read a program with an occurrence cession as a pair of views. The button takes gross / ceded; the caret beside it offers gross / net and net / ceded

Each derivation writes DecL into the editor, so you can read what it did, edit it, and build it again anywhere. The ↑ in the editor's right margin walks back through the programs you built, which is how you undo one.

Output groups
  • Overview: the distribution and its tail, then the moments and whether to believe them (Plot, Summary, Validation, Stats, Tail)
  • Re: reinsurance, ceded and net by layer, with the shape and the densities the cession leaves. The Quick Re row writes one layer into the program above, on the occurrence or the aggregate tier
  • Pricing: calibrate a distortion set to a target, price the parts stand-alone, allocate one premium across them, read the kappa curves behind the split, or evaluate a premium already set
  • PnL: a P&L's ledger, its ratios, and the margin walk
  • Bounds: how much of a price the choice of distortion decides, for the whole and for the parts
  • More: Density · Tail behavior · Window · Dependency · Sharpen · Narrative

A group or a leaf greyed out is one this object cannot answer; hover it to read why. Nothing is hidden, so the menu is always the same shape.

Tables and charts
  • Tables: static, static at full precision, or interactive, from the menu or with Ctrl+Shift+U. An interactive grid sorts, filters and searches, and its toolbar copies or saves the underlying values rather than the printed text
  • Perspective: Raw is the frame as computed, Insurer is the business reading of it. The two words beside the versions are a readout and a switch at once
  • Charts: the strip under a picture carries that panel's axis readings, log x, log y, full range, reflect, return period, invert, and its reference lines. Download saves the picture as a PNG
  • Joint surface: a relief adds contours, marginals, mesh, wall grid and lights; cut cycles through the slices; a click reads that cell out in the strip; double-click, or reset, puts the camera back. Download also writes the drawn surface as GLB, OBJ or STL, and a SpaceMouse can fly it in Chromium
