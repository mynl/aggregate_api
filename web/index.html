Quick help

The aggregate Loss Lab. Build and explore compound (aggregate) loss distributions from simple DecL programs.

Try it
agg Demo 100 claims 1000 xs 0 sev lognorm 90 cv 1.5 poisson
then press Ctrl+Enter
Keys
Ctrl+Enterbuild Ctrl+Ksearch the example library Ctrl+Spaceautocomplete Ctrl+↑ ↓step through history Ctrl+Shift+↑ ↓step through the example library (loads, does not build) ✕clear the editor
Controls
  • Build: run the program (same as Ctrl+Enter)
  • Examples: load a ready-made program
  • Sharpen: audit the grid and move to a better one, writing the hints{} clause that pins it
  • PnL: wrap what you built in a profit and loss account
  • Reset: back to the program you wrote

Each of the three writes DecL into the editor, so you can read what it did, edit it, and build it again anywhere.

Output groups
  • Overview: the distribution and its tail, then the risk tables
  • Economics: a P&L's ledger, its ratios, and the margin walk
  • Reinsurance: ceded and net by layer, with a gross / ceded / net exhibit
  • Pricing: determine a premium, or evaluate one already set
  • Bounds: pricing bounds (coming)
  • More: Validation · Stats · Density · Window · Dependency · Narrative

A group or a leaf greyed out is one this object cannot answer. Nothing is hidden, so the menu is always the same shape.
