Quick help

The aggregate Loss Library. Build and explore compound (aggregate) loss distributions from simple DecL programs.

Try it
agg Demo 100 claims 1000 xs 0 sev lognorm 90 cv 1.5 poisson
then press Ctrl+Enter
Keys
Ctrl+Enterbuild Ctrl+Ksearch the example library Ctrl+Spaceautocomplete ↑ ↓step through history Alt+↑ ↓step through examples ✕clear the editor
Controls
  • Build: run the program (same as Ctrl+Enter)
  • Examples: load a ready-made program
  • log2: FFT grid size, 2log2 buckets (auto picks it, max 16)
  • bs: bucket size / resolution (auto picks it)
Output tabs
  • Overview: what you built, its density and exceedance curve, and the risk tables
  • Plot: the object's own native plot
  • Reins: ceded / net by layer, with a gross / ceded / net exhibit
  • Price: pricing metrics and allocation analysis
  • Bounds: pricing bounds (coming)
  • More: Validation · Stats · Density · bs window · Info
