Aggregate

Build aggregate distributions from DecL and read them in cells.

=AGG.BUILD(decl, [log2], [bs])
A handle such as agg.A#4f40714271198d8f.
=AGG.EXHIBITS(handle)
The exhibits it can show.
=AGG.EXHIBIT(handle, name, [perspective], [block], [headers])
One exhibit, as values.
=AGG.Q(handle, p)
Quantiles; p a number or a range in [0, 1].
=AGG.FRAMES(handle)
The frames it has, with their shapes.
=AGG.FRAMEURL(handle, which, [format])
The URL that loads a whole frame; paste it into Data, From Web.
=AGG.LIBRARY([name], [database])
A library entry's handle; without a name, every entry as name and kind.
=AGG.PROGRAM(name, [database])
A library entry's program, as text to edit.
=AGG.VERSION()
The server's version and the library's.

References resolve to library entries only. Combine your own programs through text: =AGG.BUILD("port P " & A1 & " " & B1).

A refused program or argument comes back as #AGG! and the reason, as text you can read in the cell. Only a transient failure (unreachable, rate limited, timed out) shows #VALUE!.

Whole frames

A density frame is a table to load, not a spill. Pick the handle cell (a program is fine too), choose the frame, then paste one of the two texts below.

From Web

  1. Data, From Web.
  2. Paste the URL, OK.
  3. Load.

Cells reading -inf load as errors: right-click the column, Replace Errors, leave the value empty.

Refreshable query

  1. Name the cell holding the program Decl (Name Box, top left).
  2. Data, Get Data, From Other Sources, Blank Query.
  3. Advanced Editor, paste, Done, then Close & Load.

The query builds the program in Decl at log2 16 on every refresh, so it survives a server restart and follows an edit to the program.

Every program goes to the server and into its audit log. On a public server, never put real data in DecL.
